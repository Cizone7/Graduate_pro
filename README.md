## 一些其他
这是一个关于图标管理平台的项目，包含了基于Transformer+CNN的风格迁移模型，支付宝沙箱服务，iconify开源图标API。其余的就是基础的上传、下载、收藏、评论以及消息通知等功能。
用于管理员和用户两个角色，使用同一个登录页进行登录。
